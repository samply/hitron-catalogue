# HI-TRON Catalogue

A Vue.js application for the HI-TRON (High-Throughput Oncology) project catalogue.

## Features
- Interactive data catalogue interface
- Project search and filtering
- Detailed project views
- Cancer type and material type filtering
- Data analysis methods overview

## Tech Stack
- Vue.js 3
- Vite
- Vue Router
- FontAwesome icons

## Installation
```bash
npm install
npm run dev
```

## Build for Production
```bash
npm run build
```

## About HI-TRON
HI-TRON is focused on high-throughput oncology research and data management.
